# KosherLink Google – וואטסאפ במחשב, עם שחזור מ־Google Drive

תוכנה ל־Windows 10/11 לבעלי טלפון כשר **שהיה להם וואטסאפ וגיבו אותו ל־Google Drive**. היא מאפשרת להעביר את הוואטסאפ למחשב **עם כל ההודעות**.
האימות נעשה בשיחה קולית לטלפון הכשר.

> **אין לך גיבוי ב־Google Drive?** הגרסה הרגילה, [KosherLink](https://github.com/KatzChaim/KosherLink), קלה יותר ומתאימה לך.

## ⬇️ הורדה והתקנה

1. **[להורדת KosherLink-Google.exe](https://github.com/KatzChaim/KosherLink-Google/releases/latest/download/KosherLink-Google.exe)**. אפשר גם להוריד [חבילה עם קובץ הוראות](https://github.com/KatzChaim/KosherLink-Google/releases/latest/download/KosherLink-Google.zip).
2. מעבירים את הקובץ לתיקייה קבועה, למשל `מסמכים\KosherLink Google`, ומפעילים אותו.
3. אם מופיע "Windows הגן על המחשב": לוחצים "מידע נוסף" ואז "הפעל בכל זאת".
4. האשף מוביל שלב אחרי שלב:

| שלב | מה קורה |
|---|---|
| א. התקנה אוטומטית | הורדה של כ־1.8GB, פעם אחת. אחריה עולה טלפון וירטואלי עם שירותי Google, בעברית, ווואטסאפ מותקן בו |
| ב. תעודת סינון | **רק למי שגולש דרך סינון.** חובה לפני שלב ג׳ (ראו למטה) |
| ג. חשבון Google | נכנסים בחלון הטלפון לחשבון שאליו גובה הוואטסאפ. את הסיסמה מקלידים רק אתם |
| ד. רישום ושחזור | נרשמים בשיחה קולית, ואז בוחרים **"שחזור"** מ־Google Drive |
| ה. חיבור למחשב | מחברים את וואטסאפ ל־Windows, וכותבים ומדברים מהמחשב |

## במה זה שונה מהגרסה הרגילה

| | KosherLink (רגילה) | **KosherLink Google** |
|---|---|---|
| טלפון וירטואלי | אנדרואיד נקי, בלי Google | עם **חשבון Google ושירותי Google** |
| שחזור גיבוי מ־Google Drive | ❌ | ✅ |
| חנות Play | ❌ | ❌. וואטסאפ מותקן ומתעדכן מ־whatsapp.com |
| אפליקציות של Google (YouTube, Chrome, Maps...) | – | **מוסתרות.** נשארים רק וואטסאפ, הגדרות, אנשי קשר וקבצים |
| תעודת סינון | ✅ | ✅ |
| הורדה / זיכרון | כ־1.2GB / כ־2.5GB | כ־1.8GB / כ־3.8GB |

שתי הגרסאות יכולות להיות מותקנות באותו מחשב, וכל אחת שומרת את המידע שלה בנפרד. אבל וואטסאפ עם מספר מסוים עובד רק בטלפון אחד בכל פעם.

## סינון אינטרנט

מי שגולש דרך סינון (נטפרי, נטספארק, רימון, אתרוג ועוד) **חייב להתקין את תעודת הסינון לפני הכניסה לחשבון Google.** בלי התעודה מופיעה השגיאה "לא ניתן היה להיכנס – הייתה בעיה בתקשורת עם שרתי Google".

- באשף לוחצים **"ב. תעודת סינון"**, בוחרים את הסינון ולוחצים "התקן". אותו חלון נמצא גם בתפריט הסמל ← "תעודת סינון אינטרנט...".
- התעודות של נטפרי ושל נטספארק/רימון/אתרוג מובנות בתוכנה. לסינון אחר בוחרים קובץ תעודה מאתר הסינון.
- **נבדק:** מאחורי סינון נטספארק, עם התעודה בטלפון, הכניסה ל־Google והשחזור מ־Google Drive עבדו.

## שימוש יומיומי

- סמל **כחול** ליד השעון. לחיצה כפולה פותחת את וואטסאפ.
- בתפריט הסמל (קליק ימני): בדיקת עדכונים, הגדרות עדכון, **מהירות הטלפון** (חסכוני / מאוזן / מהיר), גיבוי, תעודת סינון, הפעלה עם Windows ויציאה.
- **עדכונים:** וואטסאפ מתעדכן מהאתר הרשמי, אחרי בדיקה שהוא חתום על ידי WhatsApp. התוכנה עצמה מתעדכנת מ־GitHub, ומקבלת רק עדכונים שחתומים במפתח של המפתח.
- **המידע נשמר רק במחשב**, בתיקייה `%LOCALAPPDATA%\KosherLink-Play`. זה השם הראשון של הגרסה, והוא נשאר כדי שהתקנות קיימות ימשיכו לעבוד.
- גיבוי יומי של השיחות והמדיה נשמר ב־`מסמכים\KosherLink Google Backup`.

## דרישות

- Windows 10/11 64 ביט, עם 16GB פנויים בדיסק ו־8GB זיכרון לפחות. מומלץ 16GB זיכרון.
- **Windows Hypervisor Platform** מופעל. אם הוא לא מופעל, התוכנה מציעה להפעיל אותו.

## בנייה ופרסום (למפתח)

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
powershell -ExecutionPolicy Bypass -File publish.ps1 -Notes "מה השתנה"
```

`publish.ps1` חותם כל גרסה במפתח הפרטי, `%USERPROFILE%\.kosherlink\update-signing-key.xml`. זה אותו מפתח של הגרסה הרגילה.
