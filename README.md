# KosherLink Play – וואטסאפ במחשב, עם Google Play

> **בפיתוח.** הגרסה הזו עוד לא מוכנה להורדה. הגרסה הרגילה והיציבה נמצאת ב־[KatzChaim/KosherLink](https://github.com/KatzChaim/KosherLink).

הגרסה הזו מיועדת **למי שכבר היה לו וואטסאפ וגיבה אותו ל־Google Drive**, ורוצה לשחזר את הגיבוי.

**ההבדל מהגרסה הרגילה:**
- **טלפון וירטואלי עם Google Play:** נכנסים לחשבון Google, מתקינים את וואטסאפ מהחנות, וכך אפשר לשחזר את הגיבוי מ־Google Drive.
- **וואטסאפ מתעדכן דרך Google Play.**
- **שתי הגרסאות יכולות להיות מותקנות באותו מחשב.** כל אחת שומרת את המידע שלה בנפרד, אבל מפעילים רק אחת בכל פעם.
- **מגבלה:** בגרסה הזו אי אפשר להתקין תעודת סינון אינטרנט. מי שגולש דרך סינון צריך לבקש מהסינון לפתוח את Google ואת וואטסאפ, או להשתמש בגרסה הרגילה.
